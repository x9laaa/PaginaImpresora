# 🖨️ Sistema de Registro de Fallos de Impresoras - Liceo

## Descripción

Este proyecto consiste en el desarrollo de una aplicación web para registrar, gestionar y dar seguimiento a los fallos de las impresoras del liceo.

El sistema permitirá llevar un control centralizado de las incidencias, facilitando el trabajo del personal encargado del soporte técnico y mejorando el tiempo de respuesta ante problemas de impresión.

## Objetivos

* Registrar fallos de las impresoras del establecimiento.
* Mantener un historial de incidencias.
* Facilitar el seguimiento del estado de cada reporte.
* Mejorar la organización del soporte técnico.

## Funcionalidades

* Registro de nuevos fallos.
* Visualización de los reportes registrados.
* Edición y actualización de incidencias.
* Eliminación de registros cuando sea necesario.
* Búsqueda y filtrado de reportes.
* Interfaz web sencilla e intuitiva.
